# Go + React Full-Stack

Full-stack app with a **Go Fiber** REST API and a **React** frontend — structured API handlers with a modern SPA client.

## Stack

- **Go** / **Fiber** — HTTP API
- **React** — frontend SPA
- REST API architecture

## Features

- Go backend with JSON REST endpoints
- React client consuming API routes
- Clear separation between API and UI layers

## Getting started

```bash
# Backend
go run .

# Frontend (if in a client directory)
npm install
npm run dev
```
